# Цели Яндекс Метрики (счётчик 110154500)

Все цели — тип **«JavaScript-событие»**, идентификатор = значение из колонки «Идентификатор».
Код отправляет их через `ym(110154500, "reachGoal", "<идентификатор>")` (src/lib/sendLead.ts).

## Основные (заявки)

| Идентификатор | Когда срабатывает |
| --- | --- |
| any_lead | Любая отправленная заявка — **главная цель для Директа** |
| hero_lead | Форма на первом экране (главная и страницы хаммама) |
| service_hero_lead | Форма на первом экране страниц услуг |
| quiz_lead | Квиз (все 9 квизов + квиз на странице хаммама) |
| header_callback | «Перезвоните мне» в шапке |
| footer_callback | «Перезвоните мне» в подвале |
| final_cta_lead | Финальный блок «Получить расчёт бесплатно» |
| pricing_lead | Блок цен / «Запросить расчёт» |
| portfolio_lead | «Хочу такой же проект» из портфолио |
| surveyor_lead | Заявка на выезд замерщика |
| project3d_lead | Заказ 3D-проекта |
| equipment_lead | Оборудование, бренды, схема оборудования |
| contact_lead | Блок «Контакты» |
| section_lead | Блоки «Готовы реализовать», «Процесс», «Под ключ» |
| callback_lead | Прочие формы «Перезвоните» |
| form_lead | Любая форма, не попавшая в правила выше |

## Контакты (тоже считаются обращением)

| Идентификатор | Когда |
| --- | --- |
| phone_click | Клик по номеру телефона |
| messenger_whatsapp_click | Переход в WhatsApp |
| messenger_telegram_click | Переход в Telegram |
| messenger_max_click | Переход в МАКС |
| email_click | Клик по e-mail |

## Микро-цели (для обучения Директа на старте)

| Идентификатор | Когда |
| --- | --- |
| form_open | Открыли любую всплывающую форму |
| quiz_start | Ответили на первый вопрос квиза (раз за визит) |
| quiz_contacts | Дошли до шага с контактами в квизе (раз за визит) |

## Сборные цели для Директа (создать в Метрике)

Тип цели — **«JavaScript-событие»**, условие — **«регулярное выражение»** (не «составная»: составная цель в Метрике — это последовательность шагов, а нам нужно «любое из»).

1. **«Обращение»** — `^(any_lead|phone_click|messenger_(whatsapp|telegram|max)_click|email_click)$`
   Её ставим в стратегию Директа, пока заявок < 10 в неделю.
2. **«Микроконверсии»** — `^(form_open|quiz_start|quiz_contacts)$`
   Для обучения стратегии и для ретаргетинга («начал квиз, но не оставил заявку»).
3. Когда any_lead набирает 10+ в неделю — стратегию Директа переводим на any_lead.
